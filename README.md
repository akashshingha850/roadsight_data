# RoadSight Dataset

A comprehensive dataset for intersection and road scene analysis using computer vision and object detection.

## 📁 Dataset Structure

```
roadsight_data/
├── train/              # Training dataset
│   ├── images/        # Training images
│   └── labels/        # Training labels (YOLO format)
├── val/               # Validation dataset
│   ├── images/        # Validation images
│   └── labels/        # Validation labels (YOLO format)
├── test/              # Test dataset
│   ├── images/        # Test images
│   └── labels/        # Test labels (YOLO format)
├── kfold/             # K-fold cross-validation splits
│   ├── split_1/       # Fold 1
│   ├── split_2/       # Fold 2
│   ├── split_3/       # Fold 3
│   ├── split_4/       # Fold 4
│   └── split_5/       # Fold 5
└── data.yaml          # Dataset configuration file
```

## 🔧 Scripts

- **annotation_preview.py** - Preview and visualize annotations
- **dataset_preview.py** - Quick dataset overview and statistics
- **data_split.py** - Split dataset into train/val/test sets
- **kfold_create.py** - Create k-fold cross-validation splits
- **instance_vis.py** - Visualize object instances
- **simple_instance_vis.py** - Simplified instance visualization

## 📊 Dataset Information

The dataset contains annotated images for road scene understanding, with labels in YOLO format (class x_center y_center width height, all normalized).

### K-Fold Cross-Validation

The dataset includes 5-fold cross-validation splits for robust model evaluation:
- Each split contains training and validation subsets
- Split configuration files: `split_X_dataset.yaml`
- Analysis report: `kfold/kfold_analysis_report.txt`

## 🚀 Getting Started

pip install opencv-python numpy matplotlib pyyaml

1. **Preview the dataset:**
   ```bash
   python dataset_preview.py
   ```

2. **Visualize annotations:**
   ```bash
   python annotation_preview.py
   ```

3. **Create custom splits:**
   ```bash
   python data_split.py
   ```

4. **Generate k-fold splits:**
   ```bash
   python kfold_create.py
   ```

## 📝 Dataset Format

- **Images:** JPG format
- **Labels:** TXT files (YOLO format)
- **Configuration:** YAML format

Each label file contains one object per line:
```
class_id x_center y_center width height
```

All coordinates are normalized (0-1 range).
